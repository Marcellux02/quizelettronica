# Quiz Elettronica

> An interactive web application for electronics and cognitive science quizzes, featuring AI-generated explanations.

**Quiz Elettronica** is a modern Single Page Application (SPA) designed to test and improve knowledge in Electronics (Semiconductors, Digital, and Analog) and Cognition & Computation. It features a sleek glassmorphism design, dynamic animations, and integrates the **Google Gemini API** to provide detailed, on-demand AI explanations for every answer.

## ✨ Features

- **Dual Quiz Modes**: Choose between Electronics or Cognition & Computation.
- **Dynamic Questions**: 20 random questions per session with automatically shuffled options.
- **Math & Science Rendering**: Full support for LaTeX formulas within questions using KaTeX.
- **AI Explanations**: Deep, contextual explanations generated by Google Gemini API for each question/answer pair.
- **Privacy First**: The API key is stored securely in your browser's `localStorage` and never sent to our servers.
- **Premium UI/UX**: Responsive design with glassmorphism effects, smooth CSS transitions, and an animated final score visualizer.

## 🚀 Quick Start

### Prerequisites
- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- A [Google Gemini API Key](https://aistudio.google.com/app/apikey) (for AI explanations)

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Marcellux02/quizelettronica.git
   cd quizelettronica
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Configure Environment Variables (Optional for dev):**
   Create a `.env` file in the root directory and add your Gemini API key (this is securely ignored by Git):
   ```env
   VITE_GEMINI_API_KEY=your_api_key_here
   ```
   *Note: You can also input the API key directly via the UI once the app is running.*

4. **Start the development server:**
   ```bash
   npm run dev
   ```
   The application will be available at `http://localhost:5173`.

### Building for Production

To build the optimized production bundle, run:
```bash
npm run build
```
The output will be placed in the `dist` directory.

## 🛠️ Tech Stack

- **Frontend Core**: React 19, Vite 7
- **Styling**: Tailwind CSS 4, react-transition-group
- **Content Rendering**: react-markdown, react-latex-next, rehype-katex, remark-math
- **Data Management**: JSON databases (`database.json`, `cognition.json`), LocalStorage API

## 📝 Modifying the Quiz Data

Questions are stored locally in the `src/` directory as JSON files:
- `src/database.json` - Electronics questions
- `src/cognition.json` - Cognition & Computation questions

To add custom questions, simply adhere to the existing JSON schema and the application will dynamically incorporate them into the quiz pool.
